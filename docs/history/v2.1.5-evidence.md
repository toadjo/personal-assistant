# v2.1.5 Release Evidence

## Summary

This release adds a redesigned Calendar panel with customizable event colors, dense month view with event bars, and a compact toolbar.

## Changes Made

### Calendar Redesign

- **Extended calendar month cells** to carry event items from both reminders and tasks
- **Implemented event bars** inside month grid with overflow handling (max 3 events per cell, "+N more" indicator)
- **Added compact toolbar** with view options: Day, Work Week, Week, Upcoming, Month, Agenda
- **Set week start to Monday** (previously Sunday)
- **Added calendar event color tokens** to theme system:
  - `calReminderBg` - Reminder event background
  - `calTaskBg` - Task event background
  - `calTaskHighBg` - High-priority task background
  - `calCompletedBg` - Completed event background
  - `calEventText` - Event text color
  - `calGridBg` - Calendar grid background
  - `calGridBorder` - Calendar grid border
- **Added default color values** for calendar tokens to all theme presets (Glass, Paper, Obsidian, Fog, Deep blue, Corporate)

### Files Modified

- `src/renderer/lib/calendar.ts` - Extended CalendarCell with events array, updated buildCalendarCells to include tasks, adjusted week start to Monday
- `src/renderer/hooks/workspace/useCalendarState.ts` - Added tasksGroupedByLocalDate helper and integrated with buildCalendarCells
- `src/renderer/lib/theme/tokens.ts` - Added calendar token keys, CSS variables, and default values for all presets
- `src/renderer/components/panels/CalendarPanel.tsx` - Added calendar toolbar, event bar rendering, and overflow handling
- `src/renderer/components/panels/CalendarPanel.css` - Added styles for toolbar and event bars

### Tests Added

- `src/renderer/lib/calendar.test.ts` - Unit tests for calendar cell building, Monday week start, event grouping
- `src/renderer/components/panels/CalendarPanel.test.tsx` - Tests for toolbar rendering, event bars, overflow indicator
- `src/renderer/lib/theme/theme.test.ts` - Test verifying all presets include calendar color tokens
- `tests/e2e/desk.spec.ts` - E2E test for calendar toolbar and Monday week start
